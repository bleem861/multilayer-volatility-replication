3. Data

The paper uses daily realized volatility and open-to-close returns from the Oxford-Man Institute Realized Library for 18 markets, covering 3000 trading days from 2010-09-14 to 2022-02-25. The supplied RV.csv and Return.csv files contain the full historical data from 2000-01-03 to 2022-02-25, with 5807 observations per market.

5. Running instructions

Run the programs from the package root. Outputs are saved to results/generated/. Section 6 lists the program, inputs, generated output and reference file for each figure and table.

Using the supplied intermediate data: Run the corresponding program listed in Section 6. Programs that require intermediate data read the supplied files in data/processed/ by default.

Regenerating intermediate data: Run the generating programs listed in Section 3, preparing their required inputs first. Newly generated files are saved to results/generated/; subsequent programs do not automatically use them. To use these files consistently, work with a copy of the package and replace the corresponding files in data/processed/ with the regenerated files, preserving their filenames and subfolder structure. Then run the dependent programs listed in Sections 3 and 6. Keep the original package and reference files unchanged.

6. Outputs and verification

For Tables 4, 5 and 6, small differences from the reference results in MCS counts and CNN, LSTM and Transformer forecasts can arise from bootstrap resampling, random initialization and training, and differences in software versions or computing environments.

For Tables 7 and 8, differences from the reference results may arise from two sources: random residual resampling in VaR estimation, which uses 5000 bootstrap draws, and stochastic elements of model training, particularly neural-network weight initialization and training-sample shuffling. These sources of variation can affect VaR forecasts and, consequently, violation rates, losses, test outcomes and model rankings.

For Fig. 2, the spring layout has no fixed random seed, so node positions may vary between runs. This affects only the visual arrangement, not the network connections or numerical calculations.

For Fig. 4, regenerating the VaR data uses 5000 bootstrap draws without a fixed random seed, so forecasts may differ from the supplied results.

For Tables C.1 through C.8, bootstrap resampling can produce different MCS counts. Random initialization and training can also affect the CNN, LSTM and Transformer results in Tables C.5 and C.8; software versions and computing environments may contribute to differences between runs.

Minor numerical variations arising from these sources are not expected to alter the main conclusions of the paper.
